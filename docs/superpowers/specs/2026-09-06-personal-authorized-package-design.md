# 个人授权本地版打包设计

**日期：** 2026-09-06  
**目标：** 将现有“深大学位英语 60 分攻关”制作成可出售的 Windows 本地授权包。买家只需解压并双击启动，不安装 Node.js、不输入命令；卖家在每次交付前可填写授权编号和压缩包密码。

## 1. 范围与边界

本期交付采用 AES-256 加密的 `.7z` 文件。每个交付包仅限个人学习使用，不提供登录、云端同步或公网访问；买家可在自己的 Windows 电脑上运行本地学习站，并在同一可信局域网内让自己的平板浏览器访问。

授权声明固定为：

> 仅授权个人学习使用，禁止转发、复制、售卖

不显示买家姓名、手机号或其他个人信息。每个包使用卖家输入的唯一授权编号，例如 `SZU-2026-001`；授权编号与买家的订单或收款记录由卖家在包外自行对应保存。

离线包无法从技术上完全阻止截图、解压后复制或再次转发。本设计的目标是阻止未获得密码者直接访问、在所有使用页面明确授权限制、并通过唯一授权编号提升泄露追溯能力；不承诺绝对防复制。

## 2. 买家交付物

卖家得到的每个文件为：

```text
深大学位英语_个人授权_<授权编号>.7z
```

文件使用 7-Zip 的 AES-256 加密，并加密文件名。买家使用 7-Zip、Bandizip 或等价工具输入卖家单独发送的密码后解压。解压目录不包含源代码、`node_modules` 或卖家生成工具，结构如下：

```text
深大学位英语_个人授权_<授权编号>/
├─ 启动学位英语题库.cmd
├─ node.exe
├─ server.mjs
├─ license.json
├─ 个人学习授权说明.txt
├─ 使用说明.txt
└─ site/                         # 生产构建后的静态学习网站
```

买家双击 `启动学位英语题库.cmd` 后，脚本通过内置 `node.exe` 启动本地静态服务器并打开默认浏览器。窗口必须保持打开；局域网平板访问地址显示在窗口中。启动器也显示授权编号和固定授权声明。

## 3. 授权信息与页面水印

`license.json` 是每包唯一的运行时数据文件，格式为：

```json
{
  "authorizationId": "SZU-2026-001",
  "notice": "仅授权个人学习使用，禁止转发、复制、售卖"
}
```

网站启动时读取该文件。加载成功后，在以下位置展示“授权编号 + 固定授权声明”：

1. 首页顶部；
2. 专题选择、完形与阅读篇章选择页；
3. 客观题练习页；
4. 汉译英与写作练习页。

若授权文件缺失、格式不正确或读取失败，页面显示“授权信息加载失败，请联系卖家”，但不伪造有效编号。授权编号仅为交付追溯标识，不收集或上传买家个人数据。

## 4. 卖家生成流程

项目根目录提供“生成个人授权包”双击工具。它依次要求卖家输入：

1. 授权编号；
2. 压缩包密码；
3. 再次输入密码确认。

输入校验规则：编号只允许字母、数字、连字符和下划线，长度 3–64；两次密码必须相同且不能为空。生成器先完成生产构建，再将内置 Node 运行时、静态站点、启动器、授权文件和说明文件装入临时目录；最后调用 7-Zip 生成 AES-256 加密 `.7z` 文件。

生成成功后，工具向卖家展示授权包路径、授权编号和 SHA-256 校验值；在授权交付清单中追加“生成时间、授权编号、文件名、SHA-256”，不记录密码。校验或打包失败时删除临时目录和不完整输出，不生成可误交付的包。

本机尚未安装 7-Zip 命令行工具。实现阶段会采用可信的 7-Zip 命令行依赖作为**卖家生成环境**的前置条件；该工具不会进入买家解压后的运行目录。若其不可用，生成器给出明确错误并停止。

## 5. 安全与可用性决策

- `.7z` 使用 AES-256 与文件名加密；密码由卖家通过与压缩包不同的渠道发送，不写入授权文件、交付清单、日志或 Git。
- 买家无需安装 Node.js；内置 Node 只运行受限本地静态服务器，服务根目录固定为 `site/` 和 `license.json`，拒绝目录遍历和非 GET/HEAD 请求。
- 本地服务默认使用受信任局域网；启动器与使用说明提醒买家仅在专用网络允许 Windows 防火墙访问。
- 局域网地址是 HTTP，可能无法使用 PWA 安装或离线缓存；直接浏览器练习不受影响。各设备的 LocalStorage 数据彼此独立。
- 可见编号和声明属于威慑与追溯措施，不应被表述为 DRM、不可复制或法律保证。

## 6. 验收与测试

实现完成时，必须验证：

1. 授权信息组件在首页与所有学习页面展示有效编号和固定声明；授权文件失败时展示明确错误；
2. 无效编号、空密码和两次密码不一致均不能生成包；
3. 生成器产物仅包含约定运行文件，不包含源码、`node_modules`、密码或卖家清单；
4. 用正确密码可测试并解压 `.7z`，错误密码无法解压；
5. 解压后双击启动器可打开本地网站，授权信息可见，局域网 HTTP 返回 200；
6. 现有单元测试、内容校验、静态检查、生产构建和 Edge 桌面/手机 E2E 均通过。

## 7. 非目标

- 不实现账号登录、设备绑定、在线激活、远程撤销或跨设备同步；
- 不保证阻止截图、录屏、人工抄录或解压后的再次转发；
- 不构成法律意见或自动完成版权登记、维权取证和合同执行。
