# 深圳大学学位英语 60 分攻关

这是一个面向深圳大学高等学历继续教育学士学位英语考试的响应式专项学习网站。学习设计以“先稳定及格”为目标：按题型和微专题短练，不要求学习者一开始完成整套模拟卷。

## 已有内容

| 模块 | 内容量 | 学习方式 |
| --- | ---: | --- |
| 诊断 | 20 题 | 先定位语法与词汇基础 |
| 语法与词汇 | 360 题 | 18 个微专题，每次 20 题 |
| 完形填空 | 12 篇、240 空 | 每次完整练一篇 20 空文章 |
| 阅读理解 | 16 篇、64 题 | 每篇 4 题，覆盖细节、词义、推断与主旨 |
| 汉译英 | 80 句 | 8 个专项，每次 10 句，先写后对照 |
| 写作 | 16 题 | 每次 1 题，三点提纲、范文与自检清单 |
| 合计 | 780 题 | 全部通过统一内容校验 |

客观题需要学习者主动核对答案；主观题先保存草稿，随后才显示参考译文或范文和自检清单。作答、草稿与复习状态保存在浏览器 LocalStorage 中。

## 本地运行

```bash
npm install
npm run dev
```

## 电脑与平板局域网访问

此版本不需要公网发布、登录或 Supabase。电脑与平板连接到同一个可信 Wi-Fi 后，可由电脑临时提供学习网站，平板直接用浏览器访问。

### 推荐：双击启动

双击项目根目录的 `启动学位英语题库.cmd`（桌面快捷方式会指向它）。它会自动构建、启动服务并打开电脑浏览器；启动窗口会显示平板需要访问的 `Network` 地址。请保持该窗口打开。

### 手动启动（仅供维护时使用）

1. 在电脑的 `web` 目录执行：

   ```bash
   npm run build
   npm run serve:lan
   ```

2. 在电脑的 PowerShell 执行 `ipconfig`，找到正在使用的 Wi-Fi 或以太网连接的 IPv4 地址，例如 `192.168.1.23`。
3. 在平板浏览器打开 `http://192.168.1.23:4173`；请将示例 IP 替换为电脑实际地址。
4. 如果 Windows 弹出防火墙提示，只允许“专用网络”。电脑不能关机或关闭该终端；终端停止后，平板将无法继续访问。

局域网地址只适合家庭或受信任网络，切勿在公共 Wi-Fi 上开放。每台设备仍将学习记录、错题和草稿独立存入自己的浏览器 LocalStorage；在本地局域网版本中，电脑与平板之间不会同步数据。通过局域网 `http` 地址访问时，部分浏览器会限制 PWA 安装和离线缓存；这是浏览器对非 HTTPS 地址的安全限制，不影响直接在浏览器中学习。

## 个人授权包（卖家操作）

个人出售时，请在项目根目录双击 `生成个人授权包.cmd`。工具会依次要求输入授权编号、压缩包密码和密码确认；编号只能由字母、数字、连字符和下划线组成，长度为 3–64 个字符，例如 `SZU-2026-001`。密码采用掩码输入，不会写入授权包、授权文件、交付清单或 Git。

生成前，卖家电脑需安装 7-Zip；本项目使用 7-Zip 的 AES-256 加密 `.7z` 格式并加密文件名。生成成功后，项目根目录的 `授权包输出` 会出现：

- `深大学位英语_个人授权_<授权编号>.7z`：交付给买家的加密包；
- `授权交付清单.jsonl`：仅卖家保留，记录生成时间、授权编号、文件名和 SHA-256 校验值，不记录密码。

将压缩包和密码通过不同渠道发送。建议卖家在包外把授权编号和 SHA-256 与订单或收款记录对应保存；不要在压缩包名称、授权文件或页面中写入买家姓名、电话等个人信息。

买家使用 7-Zip、Bandizip 或其他支持 `.7z` 的工具输入密码解压后，双击目录内的 `启动学位英语题库.cmd` 即可。授权包自带运行环境，无需安装 Node.js 或输入命令。启动窗口和学习站首页、专题页、客观题练习页、汉译英与写作练习页均会显示授权编号及固定声明：`仅授权个人学习使用，禁止转发、复制、售卖`。窗口必须保持打开；同一可信 Wi-Fi 的平板可以访问窗口显示的局域网地址。

仅在家庭或其他可信网络中允许 Windows 防火墙的“专用网络”访问，切勿在公共 Wi-Fi 共享局域网地址。各设备的学习记录、草稿和错题仍独立保存在各自浏览器中，不会同步。

AES-256 加密、固定授权声明和唯一授权编号可以阻止未获密码者直接访问，并增强泄露后的追溯能力；但解压后的文件仍可能被复制，技术手段无法绝对阻止截图、录屏、人工抄录或再次转发。请将它作为基础保护措施，不要宣称其为不可复制的 DRM 或法律保证。

## 离线安装

生产构建会生成 Web App Manifest 和 service worker。首次在联网状态打开部署站点后，浏览器会缓存已访问的页面、题库资源和本地学习状态；之后可在断网时继续使用。浏览器出现“已可离线使用”提示后，可通过地址栏的安装按钮或浏览器菜单将其安装到电脑、手机或平板主屏幕。发现新版本时，应用会显示“立即更新”按钮。

## 当前边界

- 当前版本为同一可信局域网内的本地浏览器学习版，尚未配置真实跨设备同步、账户登录或公开部署。
- `content-backup.json` 是本地导出文件，已被 Git 忽略，不会提交到仓库。
- 所有题干、文章、解析、参考译文和范文均按官方样卷的基础至中等难度原创编写；人工语言审校仍按 `docs/content-audit.md` 中的清单持续进行。
